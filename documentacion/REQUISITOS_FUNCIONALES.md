# Requisitos funcionales

**Proyecto:** Sistema Integrado de Gestión para el Laboratorio de Análisis Clínicos L&A (Lorenzo-Angeloni).

**Contexto:** Trabajo Final Integrador — Hito 2 de Metodología de Desarrollo de Software.

Estos requisitos describen funcionalidades propuestas. Su documentación no implica que el sistema esté desarrollado ni implementado.

| Identificador | Requisito funcional |
| --- | --- |
| RF-01 | El sistema debe permitir al personal administrativo registrar nuevas muestras derivadas. |
| RF-02 | El sistema debe permitir al bioquímico / técnico consultar el estado de una muestra. |
| RF-03 | El sistema debe permitir al técnico de laboratorio cargar resultados de análisis. |
| RF-04 | El sistema debe permitir al administrador gestionar usuarios y permisos. |
| RF-05 | El sistema debe permitir al personal administrativo registrar datos de pacientes. |
| RF-06 | El sistema debe permitir al administrador generar reportes del sistema. |
| RF-07 | El sistema debe permitir al personal administrativo controlar el stock de insumos y reactivos. |
| RF-08 | El sistema debe permitir al centro derivante recibir la confirmación de recepción de sus muestras y estado. |
